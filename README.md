# Self & Society — Mobile-first Reflective Learning Companion

This is a single-file prototype. Open `index.html` in any modern browser.

Core areas:
- Explore Concepts
- Build My Journal
- Challenge Me
- Reflect
- My Learning

Pedagogical loop:
NOTICE → CONNECT → QUESTION → PERSPECTIVE → ZOOM OUT → JOURNAL → APPLY

The app stores prototype progress locally in the browser using localStorage.
No server or login is required for this version.
